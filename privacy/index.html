This site

This site sets no cookies, runs no analytics, and loads no third-party scripts or fonts. Every asset is served from this domain. The background video is hosted here and plays without a network call to anyone else.

Our host records standard request data, including IP address, browser agent, and the page requested. These logs are used for security and uptime only and are retained no longer than the host's standard period.

If you write to us, we keep the correspondence and the details you send so we can answer and follow up. We do not sell it or add you to a list you did not ask for.

Client work

Data handled under a client engagement is governed by that agreement, not by this page. Where a project involves sensitive material, the terms of the engagement set how it is stored, accessed, and destroyed. Local deployments are designed so that client data does not leave client hardware.
